# 🌐 Personal Portfolio Website

Welcome to the repository of my personal portfolio website! This site serves as a digital resume and a showcase of my projects, experience, and academic background in **Artificial Intelligence, Computer Vision, and Software Engineering**.

## 🚀 Live Website
You can view the live version of this website here:
**[https://m-hajiabadi.github.io](https://m-hajiabadi.github.io)**

## ✨ Features
* **Modern UI/UX:** Clean, responsive, and minimalist single-page design.
* **Custom Loading Animation:** A smooth, branded loading screen before the content reveals.
* **Sections:** * Hero/Summary (Quick overview and social links)
    * Work Experience
    * Education
    * Key Projects & Honors
* **Fully Responsive:** Works seamlessly on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack
This project is built using pure, vanilla web technologies—no heavy frameworks required, ensuring fast load times and clean code:
* **HTML5** for semantics and structure.
* **CSS3** (with custom CSS variables and animations) for styling.
* **Vanilla JavaScript** for loading screen logic.
* **FontAwesome** for scalable vector icons.
* **Google Fonts** (Poppins) for modern typography.
